# What changed for this source snapshot

This candidate was prepared locally on October 19, 2026, from the collected lab source. The original private collection remains intact.

- Competition runtime and preparation retain separate top-level directories. Required custom sibling modules and imported legacy controller modules remain included.
- Incomplete upstream engine/frontend copies, private access/collection helpers, obsolete baseline/migration material, generated observation records, old encoded installers, archives and encrypted scoring snapshots were excluded. Readable builders remain.
- Line endings were normalized for cross-platform review. Historical shop addresses were changed to the documented fictional lab address in retained construction inputs.
- Hypervisor examples use synthetic MAC addresses and omit actual UUIDs, generation IDs and creation metadata. They require new disk allocation and host-specific review.
- `tools/prepare_workspace.py` reconstructs scorer and panel test/package layouts from this candidate alone. It refuses existing output directories.
- The portal builder resolves the included handouts locally and refuses an existing package output directory. The installer now includes `shop_probe.py` in required files, scorer/portal copies, and scorer backup/rollback handling.
- Panel tests use an attributed upstream configuration utility for real Argon2 API authentication checks. Only the full CALDERA parser integration test skips when its external checkout is absent.
- The Magma Navigation component has an explicit modification notice; upstream license/notice files are retained. No license was applied to original custom code.

The focused publication review checked credential-related literals, key headers, organizer addresses/host paths, structured configuration, encoded bundles, the participant Word document's XML/metadata, and the two selected stills. Retained tokens/passwords in tests are synthetic fixtures; lab identities, forensic answers and content fingerprints are exercise data. Public certificates and paths referring to private keys are not private key material. No completed credential sheet or live authentication/event database is included.

`tools/check_source.py` repeats syntax, local-link, selected sensitive-pattern, excluded-artifact and manifest checks. These checks are not a comprehensive vulnerability audit. Additional review is needed for any future files, deployments or generated bundles.
