# Proxmox examples

Nine VM role examples preserve observed resource allocations, device types and bridge assignments. Real MACs, SMBIOS UUIDs, generation IDs and creation metadata were removed. MACs use synthetic locally administered values; disk identifiers are illustrative. Allocate fresh storage and unique identifiers for your installation.

`interfaces.example` uses `UPLINK_INTERFACE` as a placeholder. Review your console and management path before adapting it. Organizer access relays are excluded.
